# Backlog

这里是 RAGForge 的执行板和现行说明。`specs/` 只保存 speckit 规格与 `tasks.md` 草案；真正要做、正在做、已经做完的卡片在 `tasks/`。

| 路径 | 用途 |
|---|---|
| [tasks/](./tasks/) | 任务卡。状态：To Do / In Progress / Done |
| [milestones/](./milestones/) | 里程碑 |
| [docs/architecture/doc-1 - 当前代码.md](./docs/architecture/doc-1%20-%20当前代码.md) | 正在运行的代码 |
| [docs/operations/doc-2 - 运行与安全.md](./docs/operations/doc-2%20-%20运行与安全.md) | 启动、告警、许可证 |
| [docs/operations/doc-3 - 任务与文档工作流.md](./docs/operations/doc-3%20-%20任务与文档工作流.md) | 任务板、speckit 入板、提交约定 |
| [docs/architecture/doc-4 - 业务闭环优化方向.md](./docs/architecture/doc-4%20-%20业务闭环优化方向.md) | 使用质量诊断与优化顺序 |

本地看板：`npx backlog board`（`backlog.config.yml`）。不要再把同一张卡抄进根目录长文。
