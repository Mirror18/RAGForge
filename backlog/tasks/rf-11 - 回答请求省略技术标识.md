## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`POST /api/v1/spaces/{spaceId}/answers` 在空间已有 active index、active retrieval profile、已发布 prompt 和已授权 Chat 路线时，允许省略 route、profile、prompt、model、datasetHash、configHash。服务端按 `space_id` 解析这些绑定，并写入 provenance。显式传入的 ID 仍覆盖默认值，且必须属于同一空间。

缺哪一项就返回稳定错误码：`no_active_index`、`no_active_profile`、`no_published_prompt`、`no_authorized_chat_route`、`cloud_egress_required`。禁止回落到未授权云端。引用仍来自 Evidence Bundle。
<!-- SECTION:DESCRIPTION:END -->
