## 4. Agent 执行路径

1. 读取本文件，确认当前阻塞和下一项。
2. 读取 [`09-项目任务总台账.md`](./09-项目任务总台账.md)，选择一张依赖满足的任务。
3. 按 Ticket 的 allow-list 工作；Worker 使用独立分支和 worktree。
4. 运行任务要求的测试、格式、链接、架构、安全和评估门禁。
5. 用中文 Conventional Commit 提交，并在提交正文记录真实执行细节。
6. 集成后只更新本状态快照，不把任务日志复制回 docs。
