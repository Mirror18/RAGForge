## 三、历史事实与验收记录

14–16 保存架构审计和业务闭环记录；17–25 保存阶段基准、实施结果、依赖证据和执行计划；26–33 保存阶段复盘和复盘模板。它们是历史事实，不是当前任务入口。当前任务优先看 08、09，审计级状态看 10。

## 四、根目录文件边界

- `pom.xml` 留在根目录：它是 Java 多模块 Maven reactor 的构建入口，不是普通说明文档。
- `CHANGELOG.md` 留在根目录：它是发布历史，按 Keep a Changelog 维护。
- `AGENTS.md` 留在根目录：它是仓库协作硬规则。
- `README.md` 留在根目录：它是仓库入口，只做项目概览和导航。
- GitHub 贡献/安全入口在 `.github/`；依赖许可证正文在本目录 06 号文档；Agent 经验在 13 号文档。

## 五、记录规则

文档记录稳定事实、需求目标、处理策略、验收口径和可复核摘要；某次任务实际改了什么文件、运行了什么命令、结果如何、风险和回滚方式是什么，使用 Git history：

```powershell
git log --all --oneline --grep="<任务ID>"
git show --format=fuller <commit-sha>
```

不要把聊天内容、空白占位文件或未验证的计划写成完成事实。
