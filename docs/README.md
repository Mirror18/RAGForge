## 信息优先级与记录分工

1. 根目录 [`AGENTS.md`](../AGENTS.md)：仓库硬规则和 Agent 协作约束。
2. 本页与 01–07 主文档：项目稳定事实和设计说明。
3. [项目状态卡](./08-项目状态卡.md)：日常运行快照。
4. [项目任务总台账](./09-项目任务总台账.md)：任务定义和预算真源。
5. 10–32 号记录：审计、风险、追溯、阶段证据和复盘。
6. Git history：某张任务卡实际改了什么、运行了什么命令、结果如何、风险和回滚方式是什么。

文档只记录稳定事实、任务目标、验收口径和可复核摘要；不再复制执行流水账。大段原始日志进入被忽略的临时证据目录，脱敏后的结构化结果进入 `tests/evidence/`。
