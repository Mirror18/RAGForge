# 阶段复盘

每个 Phase 使用 `YYYY-MM-DD-phase-N.md` 保存复盘。项目资料优先留在 RAGForge；工程稳定后，再由项目负责人决定把摘要写入 Obsidian 项目笔记。

模板：

```markdown
# Phase N Retrospective

## 1. Outcome and evidence

## 2. Metrics vs exit criteria

## 3. Keep

## 4. Problems

## 5. Try next

## 6. Decisions/ADRs changed

## 7. Risks opened/closed

## 8. Actions (owner, due/trigger, verification)
```

复盘必须引用真实 PR/测试/评估/演练或运行数据，不以主观总结代替证据。
