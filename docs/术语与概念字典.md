# 术语与概念字典

本文件统一产品、代码、数据库、API、事件和测试中使用的词。除非特别说明，术语均指 RAGForge 内部语义；代码标识保留英文，产品说明使用中文。

## 1. 系统边界

| 术语 | 定义 | 不应混淆 |
|---|---|---|
| **模块化单体** Modular Monolith | 多个业务模块运行在一个 Server 应用边界内，通过模块接口协作 | 不是把每个模块拆成独立微服务 |
| **Server** | 同步业务 API、认证授权、空间边界、问答编排、管理查询和审计投影所在的应用 | 不是异步摄取 Worker，也不是 AI Runtime |
| **Ingestion Worker** | 独立部署的异步任务进程，负责来源同步、解析、分块、embedding 和索引副作用 | 不是另一个面向用户的业务后端 |
| **AI Runtime** | Python 运行面，仅提供 OCR 与 rerank 能力 | 不负责业务持久化、空间管理或问答 API |
| **Frontend/Web** | Vue SPA，提供登录、空间、来源、任务、索引、问答和管理界面 | 不绕过 Server 直接访问数据库或 Provider |
| **Provider** | 可被系统调用的模型或 AI 能力供应方，包括本地 Ollama 和 OpenAI-compatible 服务 | 不是模型配置本身；配置通过 Connection/Profile/Route 表达 |

## 2. 身份、空间与权限

| 术语 | 定义 | 核心约束 |
|---|---|---|
| **User** | 登录主体，有账号、Session 和平台级身份 | 认证不等于拥有某个知识空间 |
| **Space** | 租户内容、配置、运行记录和权限的隔离边界 | 所有内容查询和变更必须带 `space_id` |
| **space_id** | 识别知识空间的稳定 ID，也是授权和数据过滤的强制字段 | 不能从 URL、前端隐藏字段或来源名称推断替代 |
| **Membership** | User 与 Space 的成员关系 | 只允许在同一 Space 内授予和检查角色 |
| **Role** | Space 内的权限角色，如 Owner、Admin、Editor、Viewer | 角色判断必须和 `space_id` 一起执行 |
| **Session** | Server 管理的浏览器登录会话 | 与模型 Provider 的凭据、Run 身份不同 |
| **CSRF** | 浏览器写操作的跨站请求伪造防护 | 不能用它代替 `space_id` 授权 |

## 3. 来源、版本与解析

| 术语 | 定义 | 核心约束 |
|---|---|---|
| **Source** | 用户配置的内容来源，如 upload、local、Git、web | 归属于一个 Space；来源 URL/路径不能作为唯一内容身份 |
| **Source identity** | 来源的稳定业务身份 | 不以 basename 或显示名称作为唯一键 |
| **Revision** | Source 在某个时间点的不可变版本 | 增量同步和重放必须明确 revision 身份 |
| **Artifact** | 某个 Revision 对应的原始或处理后物料 | 通过 hash、版本和对象位置定位，不覆盖已发布物料 |
| **content reference** | 受控地指向 artifact/chunk material 的引用 | 不等于把正文直接放进事件或日志 |
| **Object URI** | MinIO/S3-compatible object store 中的受控对象地址 | 读取前必须校验 Space、artifact 和权限 |
| **Tombstone** | 表示删除、撤销或不可再用状态的逻辑标记 | Tombstone 优先于索引和缓存，不能被旧数据复活 |
| **Connector** | 读取 upload、Git、web 或 local 来源的适配器 | 只能在授权的来源范围内读取 |
| **Checkpoint** | 来源同步进度或游标的持久化检查点 | 失败重投要从可验证的检查点恢复，不能凭内存状态猜测 |
| **Parse Report** | 解析结果、状态、页数、artifact、引擎版本和失败原因的结构化报告 | 不是简单的“解析成功”布尔值 |
| **Parser** | 将 PDF、DOCX、PPTX、XLSX、Markdown 等 artifact 转为结构化文本的组件 | 解析失败必须保留可审计原因 |
| **OCR** | 对没有可提取文本的图像内容执行文字识别 | 当前由 AI Runtime/Tesseract 受限执行，不代表所有 PDF 都有 OCR |

## 4. 分块、索引与检索

| 术语 | 定义 | 核心约束 |
|---|---|---|
| **Parent chunk** | 面向语义组织的父级文本块 | 保留 document/revision/artifact provenance |
| **Child chunk** | 用于向量/词法检索的较小文本块 | 必须能回指 parent 和原始来源位置 |
| **Chunking version** | 分块规则、长度、overlap 等配置的不可变版本 | 变更需可比较、可重建，不能覆盖历史结果 |
| **Embedding** | 文本被模型转换得到的向量 | 向量维度、模型和配置必须记录并校验 |
| **Dense retrieval** | 通过向量相似度召回 child chunk | 查询必须带 Space 和 active index 范围 |
| **BM25 / lexical retrieval** | 基于词项统计的词法召回 | 当前 lexical facts 可持久化重建，不等于内存临时索引 |
| **RRF** | Reciprocal Rank Fusion，将多路召回排名合并 | 合并结果仍要保留每路 provenance |
| **Rerank** | 对候选结果进行第二次相关性排序 | 只有真实 adapter 探测成功的能力才能进入发布闸门 |
| **Candidate index** | 正在构建、验证但尚未服务为默认结果的索引 | 验证失败不能污染 active pointer |
| **Active index** | 当前 Space 对正常查询生效的索引指针 | 只能指向通过验证的 candidate |
| **Retired index** | 不再作为当前查询入口但仍按保留策略管理的旧索引 | 退役不等于立即物理删除 |
| **Retrieval snapshot** | 一次问答使用的 index、配置、候选和结果身份快照 | 用于重放、审计和 citation 一致性 |

## 5. 问答、证据与可追溯性

| 术语 | 定义 | 核心约束 |
|---|---|---|
| **Query** | 用户提出的检索/问答输入 | 与所属 Space、Prompt 和模型配置绑定 |
| **Run** | 一次可审计的问答或 Agent 执行实例 | 有稳定 ID、Space、配置快照和生命周期 |
| **Step** | Run 内的一个阶段，如 retrieval、generation、tool | 记录状态和顺序，不替代业务事实 |
| **Invocation** | Run/Step 对 Provider 或工具的一次调用 | 记录能力、状态、耗时和脱敏 usage，不保存 raw secret/body |
| **Prompt publication** | 发布后不可变的 Prompt 版本 | Run 必须绑定实际使用的版本 |
| **Evidence** | 支撑回答的结构化证据单元 | 只能引用授权且属于当前 Space 的 material/chunk |
| **Evidence Bundle** | 一次回答可使用的证据集合及身份信息 | 是 citation 的结构化来源，不是模型生成的引用段落 |
| **Provenance** | 文档、revision、artifact、chunk、页码/范围等来源链 | 必须能从答案回到原始 material |
| **Citation** | 回答中对某个 Evidence 的结构化引用 | 不能只保存一段自由文本；要校验 allow-list 和范围 |
| **Citation range** | citation 在来源文本中的页码、字符或 token 范围 | 必须落在被授权的 material 范围内 |
| **Abstention** | 证据不足、冲突或权限不允许时明确拒答/不确定 | 不是回答失败；是可审计的安全结果 |
| **Replay** | 根据持久化 Run/Step/event 重新读取历史状态 | 不能重新调用未授权 Provider 或读取已撤权正文 |

## 6. Provider、配置与数据出境

| 术语 | 定义 | 核心约束 |
|---|---|---|
| **Connection** | Provider 的连接信息和凭据引用 | Secret 只从环境/私密配置注入，不进入 Git、日志或 evidence |
| **Model Profile** | 某个模型及其能力、维度、参数和版本声明 | 声明能力必须是 verified capability 的子集 |
| **Route** | 针对 CHAT、EMBEDDING、RERANK 等用途的调用路由 | CHAT 验证不能冒充 EMBEDDING 或 RERANK |
| **Space Binding** | 将 Space 绑定到可用 Profile/Route 的版本化配置 | 绑定具有 Space 隔离和乐观锁语义 |
| **Capability** | Provider 实际支持的用途和能力 | `declared` 不能代替 `verified` |
| **Connection test** | 用固定合成样本验证 Provider/模型/用途能力的探测 | 云探测每次都需显式授权，失败必须 fail-closed |
| **LOCAL_ONLY** | 只允许本地模型/本地 AI Runtime 的出境策略 | 本地失败不得静默 fallback 到云端 |
| **CLOUD** | 经 Space 明确授权后允许调用的云端路由 | 不是默认模式；必须记录授权和审计身份 |
| **Cloud egress** | 将 Space 内容或模型输入发送到外部网络 | 受 Space、route、URI、DNS/IP、协议和授权共同限制 |

## 7. 可靠性、治理与验证

| 术语 | 定义 | 核心约束 |
|---|---|---|
| **Outbox** | 与业务事务一起持久化、提交后再发布的消息记录 | 回滚事务不能泄露事件，发布至少一次并需幂等 |
| **Inbox / idempotency** | 消费去重和副作用幂等机制 | 重试不应重复创建业务事实或索引副作用 |
| **DLQ** | 多次失败后隔离、等待人工或策略处理的消息队列 | 进入 DLQ 不是成功，必须保留原因和重放边界 |
| **Lease** | Worker 对任务或 checkpoint 的有限期占有 | 过期后可安全恢复，不能形成永久锁 |
| **Audit event** | 面向安全、配置和生命周期操作的脱敏审计事件 | 记录主体、Space、动作和结果，不记录正文/Secret |
| **Baseline / Candidate** | 评估中用于比较的已知版本与待验证版本 | retrieval/prompt/chunk 等变更必须保留配置版本和对比结果 |
| **Fixture** | 可版本化、可重复运行的合成输入或测试数据 | 不能包含个人 Obsidian 内容、生产数据或真实凭据 |
| **Evidence JSON** | 机器可读的测试/验收结果摘要 | 只保存脱敏指标、hash、状态和引用，不保存 raw prompt/output |
| **Risk status** | 风险的 `OPEN`、`MITIGATING`、`ACCEPTED`、`CLOSED` 等状态 | `ACCEPTED` 不等于已修复；必须记录范围、批准和残余风险 |
| **ADR** | Architecture Decision Record，记录架构背景、决策、后果和约束 | Accepted 只表示决策被接受，不表示实现已完成 |

## 8. 不可违反的语义关系

1. `User → Membership → Space` 是权限链；`space_id` 必须贯穿 Source、Revision、Artifact、Index、Query、Run、Evidence、Audit。
2. `Source → Revision → Artifact → ParseReport → Parent/Child Chunk → Index → Retrieval Snapshot → Evidence → Citation` 是内容可追溯链，任何环节不能只用显示名称替代稳定身份。
3. `Connection → Profile → Route → Space Binding → Run/Invocation` 是 Provider 配置链；声明能力必须经过真实验证，调用用途必须匹配。
4. `Business transaction → Outbox → Consumer → Idempotency/Inbox → Side effect` 是异步可靠性链；重试、重复和乱序必须可安全处理。
5. `Requirement → Task card → Code/test/evidence → Git commit` 是需求闭环链；需求文档写目标和效果，Git history 写实际改动与执行细节。
