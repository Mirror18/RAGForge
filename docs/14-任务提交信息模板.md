# 任务提交信息模板

本文件只保存 Git commit 正文模板，不记录具体任务日志。任务的实际执行内容、影响文件、验证结果、风险和下一步，必须写入对应提交正文，由 Git 保存提交哈希、作者和时间。

## 1. 提交规则

- 提交主题使用中文 Conventional Commit：`<type>(<scope>): [<任务ID>] <中文摘要>`。
- 一个任务可以有多个原子提交，但每个提交只描述自己实际完成的范围。
- `DONE` 只能在目标、验证和提交都完成后写入 [项目任务总台账](./09-项目任务总台账.md)。
- 不在本文件追加任务运行日志，也不为补录历史提交创建重复文档。

## 2. 提交正文模板

```text
<type>(<scope>): [<任务ID>] <中文摘要>

任务 ID：<任务编号>
任务目标：<本次提交完成的目标>
完成内容：<实际完成内容>
影响文件：<实际修改路径>
验证命令与结果：<真实命令和结果摘要>
风险或遗留问题：<风险、阻塞或无>
回滚方式：<回滚提交、迁移或配置说明>
下一步：<后续任务 ID 或无>
```

历史查询示例：

```powershell
git log --all --oneline --grep="P7C-06"
git show --format=fuller <commit-sha>
```
